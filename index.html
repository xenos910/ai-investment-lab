♧ Core Concept

三個引擎，組成一套 AI 智能投資分析

Prompt 負責溝通需求，Python 負責精準計算，AI 負責生成解讀，Streamlit 負責展示成果。

⌘Compute

Python 是計算引擎

負責資料整理、技術指標計算、策略回測、投資組合權重與風險模擬。

✧Explain

Gemini API 是報告引擎

負責把數據、圖表與績效結果轉換成有結構的 AI 分析報告與解讀。

▣Deploy

Streamlit 是展示平台

負責把 Python 模組包裝成可以互動操作的網頁介面，讓使用者展示成果。
